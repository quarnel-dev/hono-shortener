# Hono URL Shortener

[Читать на английском](README.md) | Русский

Минималистичный и быстрый REST API для сокращения ссылок, написанный на Hono, Bun, Valibot и OpenAPI.

## Особенности

- **Валидация:** Проверка входных данных в runtime с помощью Valibot.
- **OpenAPI / Scalar:** Интерактивная документация на `/scalar` (отключается в production).
- **Обработка ошибок:** Единый формат JSON-ответов (`{ "error": "..." }`).
- **Тесты:** Полный комплект E2E-тестов через `bun:test`.

## Быстрый старт
```bash
bun install
bun dev
```

- **Сервер:** http://localhost:3000
- **Документация:** http://localhost:3000/scalar

## Скрипты

- `bun dev` — Запуск сервера в режиме разработки (watch mode)
- `bun start` — Запуск в продакшен-режиме
- `bun test` — Запуск unit и E2E тестов

## API Эндпоинты    

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `POST` | `/links` | Создать короткую ссылку |
| `GET` | `/links` | Получить список всех ссылок |
| `GET` | `/links/:code/stats` | Получить статистику переходов по коду |
| `DELETE` | `/links/:code` | Удалить ссылку |
| `GET` | `/:code` | Редирект на оригинальный URL (302) |
